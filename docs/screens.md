# 畫面與操作規格（v1）

> 對應 `docs/design.md` v4。2026-11-06 已依此實作前端（`frontend/src/pages`），差異見 design.md 第 10 節「實作後的小項」。桌面瀏覽器為主，安燈季櫃台要能全鍵盤操作。配色為現代明亮色系：白底、淺灰背景、藍色主色。年份與日期一律顯示民國。可操作原型：https://claude.ai/artifact/7AzWsXEuEikrD25j2StReh

## 全域

- 登入後才能進任何頁。頁首固定顯示：寺廟名稱、**目前年度（民國）**、登入者、角色。
- 主選單：櫃台、戶籍、收款與日結、列印、燈種、設定、使用者（ADMIN）、稽核（ADMIN）。
- 所有「存檔」都在同一個 transaction 完成，成功後畫面顯示結果，失敗整個不寫。
- 快捷鍵：`/` 跳到搜尋，`Enter` 開啟第一筆，矩陣內方向鍵移動、空白鍵勾選、`Ctrl+Enter` 存檔。

## 1. 登入

帳號、密碼。失敗訊息不區分帳號不存在或密碼錯。停用帳號不能登入。

## 2. 櫃台：搜尋戶

| 元素 | 說明 |
| --- | --- |
| 搜尋框 | 一個框打戶長姓名、任一成員姓名、電話或戶號，即時列出結果 |
| 結果列 | 戶號、戶長、區、成員數、今年已安燈數、電話 |
| 新增戶 | 搜不到時按此，進第 4 畫面 |

同名時結果列並排顯示電話與地址供分辨。選一列進第 3 畫面。

## 3. 櫃台：戶頁（核心畫面）

### 上半部：戶資訊

戶號、戶長、縣市鄉鎮市區、地址、電話、聯絡備註、備註。「編輯」開第 4 畫面。

### 中段：成員 × 燈種矩陣

- 列是成員，戶長第一，其餘依戶內排序；已刪除成員不顯示。每列顯示姓名、性別、生肖、生辰縮寫。
- 一般燈三欄固定顯示，標頭只有燈名，不顯示價格；「顯示價格」開關打開才在標頭帶出價格。
- 格子像核取方塊：點一下勾選、再點一下移除。已安的燈顯示藍勾，本次新勾綠勾並標「新」，取消已安的燈變成空格並標紅字「取消」。
- 八卦轉運斗不排 23 欄：每位成員那一列的下方直接排出 23 型的按鈕，自動換行，點一下選、再點一下取消，不需要先展開。右上角「顯示八卦斗」開關可整個收起，給不安斗的戶用。價格只在「顯示價格」打開時出現在按鈕上。
- 犯太歲的成員整列淡黃底，太歲燈那格顯示「建議」提示但不自動勾。
- 列尾操作：編輯成員、刪除成員、設為戶長、移戶、上下移動排序。
- 矩陣下方一列「新增成員」可直接輸入姓名與性別後按 Enter 加入，生辰之後再補。

### 右側或下方：本次應收

| 行 | 內容 |
| --- | --- |
| 新增 | N 盞，合計 X 元，逐項列出成員與燈種 |
| 取消 | M 盞，折抵 Y 元 |
| 應收 | Z 元，為負時顯示「不退費，差額轉功德金」 |

- ADMIN 可點任一新增項目改單價，必填原因。
- 「補登」開關：打開後出現「登記日」與「收款日」兩個日期欄，預設上一筆的值。
- 「存檔並收款」：彈出確認框重述應收金額，確認後寫入，成功後顯示「列印本戶安燈卡」與「繼續下一戶」。
- 未存檔就離開頁面要提示。

### 下半部：本戶歷史

- 單據列表：日期（民國）、種類（櫃台、更正、匯入）、應收、已結清、狀態、開單人。點開進第 6 畫面。
- 年度切換器：看其他年度的矩陣，唯讀。

## 4. 新增與編輯戶

戶號（新增時自動，唯讀）、縣市與鄉鎮市區兩層下拉、地址、電話、聯絡備註、備註。新增戶時同一表單底下直接填第一位成員，自動設為戶長。

## 5. 編輯成員

| 欄位 | 輸入方式 |
| --- | --- |
| 姓名、性別 | 文字、單選 |
| 干支年 | 文字框打一到兩個字即自動補全 60 甲子；「吉」按鈕清空 |
| 月、日 | 數字；「吉」按鈕清空 |
| 閏月 | 勾選，月為空時不可勾 |
| 時辰 | 十二地支按鈕列；「吉」按鈕清空 |
| 縣市、鄉鎮市區、地址 | 兩層下拉加文字；空白代表沿用戶的 |
| 電話 | 選填 |

儲存時顯示換算後的生肖讓操作者核對。刪除成員要填原因（資料面是軟刪除）；刪的是戶長時要求先指定新戶長。

## 6. 單據詳情

- 標頭：單號、種類、年度、戶、登記日、入帳日、開單人、狀態。
- 明細：成員、燈種、動作、單價、改價原因。
- 收款：每筆的種類、金額、收款日、收款人、備註。結清狀態與差額。
- 動作（ADMIN）：
  - 入帳日尚未日結：「作廢」，填原因，確認後現金退還提示。
  - 入帳日已日結：「開更正單」，進第 7 畫面。
  - 更正單可追溯顯示原單連結。

## 7. 更正單

- 從原單開啟，矩陣預載原單那一戶，可用搜尋把其他戶的成員加進來（跨戶更正）。
- 勾選方式同櫃台矩陣。
- 差額區顯示：應補收、應退、或零。結清方式單選：收現、退現、放棄退款轉功德金、留待處理。
- 必填更正原因。存檔後原單不變，列表上原單標示「已被更正」並連到更正單。

## 8. 收款與日結

### 今日收款

時間、戶、單號、種類、金額、收款人。底部系統合計，只算 CASH。

### 日結

- 輸入實點現金，系統即時算長短款，可填備註。
- 「完成日結」確認後該日凍結，提示「今日單據已不可作廢」。
- 關帳日之前的日期不可再補登或作廢，介面上相關按鈕直接隱藏並說明原因。

### 差額待處理

列出結清狀態不為零的單，點開進第 6 畫面處理。

### 日結歷史

日期、系統合計、實點、長短款、日結人、備註。

## 9. 列印

- 選年度與燈種，三個按鈕：安燈卡、頌經名冊（今年）、全部名冊。
- 產生 PDF 後在新分頁預覽，可下載，自動存入歸檔目錄並列在下方「歸檔」清單可重印。
- 戶頁的「列印本戶安燈卡」只印該戶該次新增的卡。

## 10. 燈種管理

列表：分類、名稱、縮寫、價格、排序、啟用、太歲燈標記。可新增、編輯、停用。改價只影響之後的單。太歲燈標記只能有一種。

## 11. 設定

- 目前年度：改動需二次確認，說明效果。
- 寺廟名稱與地址（列印用）。
- 太歲規則：值、沖、刑、害、破五個勾選。
- 祈福文月份。

## 12. 使用者（ADMIN）

新增、停用、重設密碼、角色。不能停用自己。

## 13. 稽核（ADMIN）

依表、對象、人、日期篩選，每筆顯示修改前後的差異欄位。

## 角色對照

| 功能 | STAFF | ADMIN |
| --- | --- | --- |
| 櫃台登記、補登、收款、日結 | 可 | 可 |
| 戶與成員新增、編輯、刪除、移戶 | 可 | 可 |
| 改單價、作廢、更正單 | 不可 | 可 |
| 燈種、設定、使用者、稽核 | 唯讀或不可見 | 可 |
