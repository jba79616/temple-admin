# 畫面與操作規格（v1）

> 對應 `docs/design.md` v4。2026-11-06 已依此實作前端（`frontend/src/pages`），差異見 design.md 第 10 節「實作後的小項」。桌面瀏覽器為主，安燈季櫃台要能全鍵盤操作。配色為現代明亮色系：白底、淺灰背景、藍色主色。年份與日期一律顯示民國。可操作原型：https://claude.ai/artifact/7AzWsXEuEikrD25j2StReh

## 全域

- 登入後才能進任何頁。頁首固定顯示：寺廟名稱、**目前年度（民國）**、登入者、角色。
- 導覽分兩層。桌面：頁首左邊五個分頁「櫃台、戶籍、收款與日結、列印、帖子名單」，右邊「管理」下拉收「燈種與價格、設定、使用者（ADMIN）、稽核（ADMIN）、舊資料匯入（ADMIN）」。手機（640px 以下）：頁首只留廟名與年度，底部固定五顆 tab「櫃台、戶籍、日結、列印、更多」，「更多」頁列出帖子名單、管理項目與登出。戶頁、成員、單據都算在「櫃台」底下，tab 會亮。
- 麵包屑：櫃台底下的每一頁最上面固定一條「櫃台 › 戶 5 李國華 › 改生辰資料：李國華」，每一層可點回去。
- 所有「存檔」都在同一個 transaction 完成，成功後畫面顯示結果，失敗整個不寫。
- 快捷鍵：`/` 跳到搜尋，`Enter` 開啟第一筆，矩陣內方向鍵移動、空白鍵切換、`Ctrl+Enter` 存檔。

## 1. 登入

帳號、密碼。失敗訊息不區分帳號不存在或密碼錯。停用帳號不能登入。

## 2. 櫃台：搜尋戶

| 元素 | 說明 |
| --- | --- |
| 搜尋框 | 標題「安燈、改資料、看紀錄：先找這一戶」，一個框打戶長姓名、任一成員姓名、電話或戶號，即時列出結果；框下一行三步驟提示（找戶 → 點燈種按鈕 → 存檔收款、印安燈卡） |
| 今天小卡 | 搜尋框空白時顯示：今日收款筆數、現金合計、是否已日結，附「去日結」「去列印」；開始打字就收起 |
| 新增戶小卡 | 搜尋框空白時顯示「第一次來的信眾」說明與「新增戶」；打字後結果表下方仍有「找不到這一戶？新增戶」 |
| 結果列 | 戶號、戶長、區、成員數、今年已安燈數、電話 |

同名時結果列並排顯示電話與地址供分辨。選一列進第 3 畫面。

## 2b. 戶籍

全部成員的生辰與住址清單，頁首分頁「戶籍」（手機底部 tab 也有）。

| 元素 | 說明 |
| --- | --- |
| 檢視切換 | 「人員（照編號）」：一人一列，照成員編號排序；「戶（點箭頭展開）」：一戶一列，照戶號排序，戶列顯示戶長本人的資料，第一欄的箭頭往下展開同戶其他成員，欄位與人員檢視相同（資料隨戶列一起載入，展開不等待）。兩種都每頁 10 筆 |
| 只看今年有安燈的 | 勾選後兩種檢視都只列今年狀態表有燈的人或戶 |
| 人員欄位 | 編號、戶號（連到戶頁）、姓名（連到改生辰資料）、性別、生辰、生肖（今年犯太歲的黃底，滑過顯示值沖刑害破）、住址（成員沒填就沿用戶的）、今年安燈（燈種簡稱）、電話 |
| 戶欄位 | 與人員欄位相同，第一欄改成展開箭頭，戶號下方小字「N 人 · N 盞」；只有戶長一人的戶沒有箭頭 |
| 分頁 | 上一頁／下一頁與「共 N 筆、第 x / y 頁」，檢視、篩選、頁碼都記在網址，返回時位置不變 |

資料來自 `GET /api/registry/members` 與 `GET /api/registry/households`（參數 `page`、`size`、`lit`、`year`），戶列回應內含同戶成員列。

## 3. 櫃台：戶頁（核心畫面）

### 上半部：戶資訊

戶號、戶長、縣市鄉鎮市區、地址、電話、聯絡備註、備註。「改地址電話」開第 4 畫面。

### 中段：成員 × 燈種矩陣

- 列是成員，戶長第一，其餘依戶內排序；已刪除成員不顯示在矩陣，戶有已刪除成員時在單據上方多一個可展開的「已刪除成員（N）」卡，列姓名、性別、生辰、刪除時間、原因與「復原」。復原後排在成員列最後，戶內沒戶長時直接成為戶長，歷年安燈紀錄本來就都在。每列顯示姓名、性別、生肖、生辰縮寫。
- 一般燈三欄固定顯示，標頭只有燈名，不顯示價格；「顯示價格」開關打開才在標頭帶出價格。
- 矩陣卡標題下一行提示「點燈種按鈕安燈或取消，改好後按『存檔並收款』。改生辰、地址用旁邊的按鈕。鍵盤：方向鍵在格子間移動、空白鍵切換、Ctrl+Enter 存檔」。每位成員列右邊是「改生辰資料」與「設為戶長」。
- 鍵盤：焦點在燈種按鈕上時左右鍵在同一位成員的燈種間移動，上下鍵換成員、停在同一個燈種；空白鍵切換；`Ctrl+Enter`（Mac `⌘+Enter`）第一次按等於按「存檔並收款」，確認面板出現後再按一次等於「確認收款」。
- 光明、文昌、太歲三盞燈是每位成員列上的三顆按鈕，名稱寫在按鈕上，跟八卦斗同一套樣式：狀態只用顏色表示，已安藍底，點一下新增變綠底，再點取消；點已安的燈變紅框劃線表示本次取消，再點復原。按鈕下方那行只放價格（打開「顯示價格」時）或太歲燈的「建議」，高度固定，切換狀態時版面不動。沒有表頭列。
- 八卦轉運斗不排 22 欄：每位成員那一列的下方直接排出 22 型的按鈕，自動換行，點一下選、再點一下取消，不需要先展開。右上角「隱藏一般燈」「隱藏八卦斗」兩個開關可分別收起光明文昌太歲與八卦斗，只處理其中一種時畫面清爽。價格只在「顯示價格」打開時出現在按鈕上。手機（寬度 720px 以下）預設收起，要安斗再打開。
- 手機版矩陣：成員一列是姓名加操作按鈕，三顆燈種按鈕平分下一列。畫面底部黏一條「本次應收 / 存檔並收款」列，按下去捲到應收面板並進入確認。
- 犯太歲的成員整列淡黃底，太歲燈按鈕變虛線黃框標「建議」但不自動選。
- 列尾操作：編輯成員、刪除成員、設為戶長、移戶、上下移動排序。
- 矩陣下方一列「新增成員」可直接輸入姓名與性別後按 Enter 加入，生辰之後再補。

### 右側或下方：本次應收

| 行 | 內容 |
| --- | --- |
| 新增 | N 盞，合計 X 元，逐項列出成員與燈種 |
| 取消 | M 盞，折抵 Y 元 |
| 應收 | Z 元，為負時顯示「不退費，差額轉功德金」 |

- ADMIN 可點任一新增項目改單價，必填原因。
- 「補登」開關：打開後出現「登記日」與「收款日」兩個日期欄，預設上一筆的值。
- 「存檔並收款」：彈出確認框重述應收金額，確認後寫入，成功後顯示「列印本戶安燈卡」與「繼續下一戶」。
- 未存檔就離開頁面要提示。

### 下半部：本戶歷史

- 單據列表：日期（民國）、種類（櫃台、更正、匯入）、應收、已結清、狀態、開單人。點開進第 6 畫面。
- 年度切換器：看其他年度的矩陣，唯讀。

## 4. 新增與編輯戶

戶號（新增時自動，唯讀）、縣市與鄉鎮市區兩層下拉（鄉鎮市區旁顯示 3 碼郵遞區號，查無時提示確認名稱）、地址、電話、聯絡備註、備註。新增戶時同一表單底下直接填第一位成員，自動設為戶長。

## 5. 編輯成員

| 欄位 | 輸入方式 |
| --- | --- |
| 姓名、性別 | 文字、單選 |
| 干支年 | 文字框打一到兩個字即自動補全 60 甲子；「吉」按鈕清空 |
| 月、日 | 數字；「吉」按鈕清空 |
| 閏月 | 勾選，月為空時不可勾 |
| 時辰 | 十二地支按鈕列；「吉」按鈕清空 |
| 縣市、鄉鎮市區、地址 | 兩層下拉加文字；空白代表沿用戶的 |
| 電話 | 選填 |

沒有修改時「儲存」按鈕停用；有修改時按鈕旁顯示「有未儲存的修改」，儲存成功後按鈕旁顯示「已儲存 時間」並在按鈕下方顯示換算後的生肖與太歲讓操作者核對（放在按鈕旁而不是頁首，手機上才看得到）。刪除成員要填原因（資料面是軟刪除）；刪的是戶長時要求先指定新戶長。

## 6. 單據詳情

- 標頭：單號、種類、年度、戶、登記日、入帳日、開單人、狀態。
- 明細：成員、燈種、動作、單價、改價原因。
- 收款：每筆的種類、金額、收款日、收款人、備註。結清狀態與差額。
- 動作（ADMIN）：
  - 入帳日尚未日結：「作廢」，填原因，確認後現金退還提示。
  - 入帳日已日結：「開更正單」，進第 7 畫面。
  - 更正單可追溯顯示原單連結。

## 7. 更正單

- 從原單開啟，矩陣預載原單那一戶，可用搜尋把其他戶的成員加進來（跨戶更正）。
- 點選方式同櫃台矩陣。
- 差額區顯示：應補收、應退、或零。結清方式單選：收現、退現、放棄退款轉功德金、留待處理。
- 必填更正原因。存檔後原單不變，列表上原單標示「已被更正」並連到更正單。

## 8. 收款與日結

### 今日收款

時間、戶、單號、種類、金額、收款人。列出上次日結之後到今天入帳的所有收款（匯入資料不列），底部系統合計，只算 CASH。

### 日結

- 輸入實點現金，系統即時算長短款，可填備註。
- 「完成日結」確認後該日凍結，提示「今日單據已不可作廢」。
- 關帳日之前的日期不可再補登或作廢，介面上相關按鈕直接隱藏並說明原因。

### 差額待處理

列出結清狀態不為零的單，點開進第 6 畫面處理。

### 日結歷史

日期、系統合計、實點、長短款、日結人、備註。最新一筆有「修改實點」：展開後填新的實點金額與原因（必填），確認後系統合計不變、長短款重算，該列下方顯示「原實點 X，誰 何時 改：原因」。更早的日結不能改，差額請開更正單對銷。

## 9. 列印

- 選年度與燈種，兩個按鈕：安燈卡、疏文（該年點了這種燈的人）。燈種下拉只列光明、文昌、太歲和「八卦轉運斗」一項，選八卦轉運斗就把 22 型合在一起印：安燈卡燈名印「八卦轉運斗」加型名，疏文同一人只列一次。
- 列印頁在新分頁開啟，右上角「列印」與「下載 PDF」；列印首頁也有「下載 PDF 檔，不開列印頁」開關，打開後各按鈕直接下載伺服器轉好的 PDF（檔名取報表名稱與年度）。伺服器沒裝 Chrome/Edge 會提示改用瀏覽器列印。沒有歸檔目錄。
- 戶頁的「列印本戶安燈卡」只印該戶該次新增的卡。
- 申報單區塊：選年度（預設去年），三個按鈕：申報單（該年有安燈的人）、申報單（全部的人）、八卦轉運斗（該年有安斗的人）。A4 直印一戶一頁（左右各留 5mm），版面照舊系統 .rtm 還原後整張縮 1.6% 放進 A4，勾選框與手寫框留白給信眾填，字型內建楷體。
- 帖子寄送標籤區塊：一顆按鈕「帖子標籤」，印帖子名單裡標為寄送的收件人，依郵遞區號排序（沒郵遞區號的排最後），A4 標籤紙一頁 14 張（2×7，99.1×38.1mm），每張上行郵遞區號加地址、下行姓名加「收」；連到戶的印戶長與戶地址。畫面上有虛線框對位，列印時不印。

## 9b. 帖子名單

- 桌面頁首「帖子名單」，手機「更多 → 帖子名單」。STAFF 與 ADMIN 都能看、新增、編輯、暫停；刪除只有 ADMIN（後端也擋）。
- 頂端統計「寄 N · 暫停 N · 國外 N（不寄）· 連到戶 N」與查不到郵遞區號的筆數；按鈕「標籤列印頁」（新分頁開 `/print/labels`）、「下載標籤 PDF」、「新增收件人」。
- 搜尋框比姓名、戶長、收件人、地址、備註、來源、戶號；篩選「全部／寄送／暫停／國外／沒連到戶」。表格預設每頁 10 筆（可改 20／50／100，瀏覽器記住），上下各一組「上一頁／下一頁」，改搜尋或篩選就回到第 1 頁。
- 表格每列：郵遞區號（連到戶的依戶的縣市鄉鎮查，查不到用名單上的）、收件人（連到戶且覆寫時下方小字顯示戶長）、地址、戶（可點進戶頁）、來源／備註、狀態、動作「編輯、暫停／恢復、刪除」。暫停的列淡化。地址不是臺灣的列（拆不出臺灣縣市，又出現國名、省名、英文國名，或整串都是英文；金門、連江的「福建省」不算，中文地址夾幾個英文字母也不算）狀態顯示「國外不寄」，一樣淡化、標籤不印、不算在「寄」裡；要寄就把地址改成臺灣地址。
- 新增表單在頂端展開；編輯表單展開在該列正下方（再按一次「編輯」收起），手機上釘在畫面左邊不跟著表格橫捲。欄位：戶號（填了就連到戶，寄給戶長、用戶地址，地址欄收起來）、收件人（連到戶時空白＝戶長）、郵遞區號（留空會依地址自動查，打地址時欄位灰字即時顯示查到的 3 碼，查不到才需要手動填；連到戶的依戶地址查）、地址（沒連到戶必填）、備註、「寄送」勾選。存檔規則由後端擋：沒連到戶要有姓名與地址；郵遞區號 3 或 5 碼；一戶只能一列；編輯時帶著讀出的版本，別人中途改過就擋下請重新整理。地址存檔時會整理成「台→臺、中文間不留空白、開頭郵遞區號去掉」。暫停／恢復只改寄送狀態，不會動到其他欄位。
- 戶頁上半部多一個「寄帖」勾選：勾了就把這戶加進名單（寄給戶長、用戶地址），取消是暫停不是刪除；名單上有覆寫收件人或備註時旁邊顯示小字連到名單頁，戶地址不是臺灣時顯示「國外地址不寄」。

## 10. 燈種管理

列表：分類、名稱、縮寫、價格、排序、啟用、太歲燈標記。可新增、編輯、停用。改價只影響之後的單。太歲燈標記只能有一種。

## 11. 設定

- 目前年度：改動需二次確認，說明效果。
- 寺廟名稱與地址（列印用）。
- 太歲規則：值、沖、刑、害、破五個勾選。
- 祈福文月份。

## 12. 使用者（ADMIN）

新增、停用、重設密碼、角色。不能停用自己。

## 13. 稽核（ADMIN）

依表、對象、人、日期篩選，每筆顯示修改前後的差異欄位。

## 14. 舊資料匯入（ADMIN）

桌面「管理 ▾ → 舊資料匯入」，手機「更多 → 舊資料匯入」。選舊系統的 mysqldump 檔（.sql、UTF-8）後先按「預覽」：後端把整個流程跑完再 rollback，回報表但不留資料；報表看過沒問題再按「正式匯入」（有確認框，匯入單不能作廢）。報表內容：舊資料人數與其中已刪除的人數（也匯入，建成軟刪除成員，歷年安燈紀錄照補，另計「含已刪除成員 N 筆」）、戶與成員的新建／更新數、匯入單／明細／收款筆數、地址拆分結果、歷年各燈種人數表，以及分組可展開的「需要人工看的項目」（地址拆不出縣市、缺鄉鎮市區、戶長、生辰、姓名與性別、成員順序），每筆帶戶號、姓名、說明。同一份 dump 可重跑，不會重複建單；新系統已設的戶長與聯絡備註重跑時不動。

同一頁下方「帖子名單匯入」：上傳 CSV（Excel 另存「CSV UTF-8」，Big5 也收），第一列欄名「戶號、姓名、地址、郵遞區號、收件人、備註、來源」，順序任意、可缺欄。有戶號的列連到戶（寄給戶長、用戶地址，填收件人才覆寫），沒戶號的列用姓名地址建獨立收件人。一樣先「預覽」再「正式匯入」；報表顯示資料列、連到戶、獨立收件人、略過數，以及分組的「需要人工看的項目」（戶號找不到或不是數字、缺姓名或地址、郵遞區號格式、重複），每筆帶第幾列與姓名。同一戶與同名同地址只留第一筆，重跑不會重複。
